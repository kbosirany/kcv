# Répertoire images

Placez vos images dans ce dossier :

- `photo.jpg` ou `photo.png` : Photo professionnelle pour l'en-tête
- Logos d'entreprises ou d'universités (optionnel)
- Captures d'écran de projets (optionnel)

## Format recommandé pour la photo

- Format : JPG ou PNG
- Taille : 3x4 cm (environ 300x400 pixels)
- Fond : Neutre et uni
- Style : Professionnel

## Usage

Dans vos fichiers `.tex`, référencez les images avec le chemin relatif :

```latex
\includegraphics[width=3cm]{../images/photo.jpg}
```
