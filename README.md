# kcv

Single repository to write and produce the CVs of Kevin and his relatives. You describe a
background **in your own words** (in French, in `background/*.md`); Claude turns it into a
structured fact sheet, then into a targeted CV compiled to PDF.

```
free narrative  ──►  fact sheet  ──►  targeted CV (PDF)  ──►  portfolio (optional)
background/*.md      facts.yml        cvs/<target>/cv.tex     kbosirany/kportfolio
```

All file names, keys, scripts and documentation are in English. Only the content of
`background/*.md` (the narrative) and the CV content derived from it is in French.

## Layout

```
people/<person>/
  person.yml          display name, contact details, photo, default template
  background/*.md     THE NARRATIVE (source of truth), free text in French
  facts.yml           structured fact sheet, generated by Claude and reviewed
  photo.jpg
  cvs/<target>/
    brief.md          target, language, length; its YAML header picks the template
    cv.tex            the CV, written by Claude from facts.yml + brief.md
templates/<name>/     layout only, no data (see TEMPLATE.md)
schemas/              schema of facts.yml
scripts/              validate.py, build.py
archive/              old repositories (kcv v1, kcv2, kcv.mum), for reference
.claude/skills/       new-person, update-facts, generate-cv
```

Current people: `kevin`, `mum`. To come: `kelly` (sister), `vivi` (fiancée).

## Day to day

1. **Write or complete the narrative** in `people/<person>/background/`. No format, no length
   limit. Lines starting with `> À compléter :` show what is missing.
2. **Ask Claude** "update <person>'s fact sheet": it reads the narrative, updates `facts.yml`
   and shows what changed. Review it.
3. **Ask for a CV**: "CV for <person> for <job>, 1 page". Claude creates
   `cvs/<target>/brief.md` and `cv.tex`; CI builds the PDF.

Golden rule: a CV only contains what is in `facts.yml`, and `facts.yml` only contains what is in
the narrative. Nothing is invented.

## Add a person

Ask "create <name>", or copy `people/mum/` and empty `background/` and `facts.yml`.

## Build locally

```sh
pip install -r requirements.txt
python scripts/validate.py                 # fact sheets, briefs, templates
python scripts/build.py                    # all CVs -> dist/
python scripts/build.py kevin/general      # a single one
```

You need `latexmk`, `lmodern`, `texlive-latex-extra`, `texlive-fonts-extra` and
`texlive-lang-french`. CI (`.github/workflows/build.yml`) does the same on every push and pull
request; the PDFs are in the run's artifacts. PDFs are not committed.

## Link with the portfolio

The portfolio ([kportfolio](https://github.com/kbosirany/kportfolio), an Astro site on GitHub
Pages) shows a list of CVs described in its `data/cv.yml` and reads the PDFs from `public/cv/`.
kcv is the only source of those PDFs:

- A brief containing `portfolio: cv-fr.pdf` (in its YAML header) flags a CV to publish under that
  file name; the name must match `fichier:` in the portfolio's `data/cv.yml` (`cv-fr.pdf`,
  `cv-en.pdf`). Without that line the CV stays private: this is the case for everyone but Kevin.
- `.github/workflows/portfolio.yml` builds, then opens a pull request on kportfolio with the PDFs
  in `public/cv/`. The portfolio's deployment stays its own, and you review the PR.
- One-time setup: create a GitHub token scoped to the kportfolio repository (Contents and Pull
  requests, read/write) and save it as the `PORTFOLIO_TOKEN` secret in kcv. Without the secret
  the workflow does nothing.

Even if kcv becomes private, the portfolio does not depend on kcv to build: it receives PDFs in
its own repository. Kevin's `facts.yml` could later also feed the portfolio's
`data/competences.yml` and `data/projets.yml` (one source, several outputs); not done yet since
the portfolio is under construction.

## Privacy

The narratives contain personal data about relatives (address, phone, background).
Recommendation: make this repository **private** (Settings > General > Danger Zone). CI artifacts
are then only available to collaborators, and only CVs flagged `portfolio` leave the repository.
